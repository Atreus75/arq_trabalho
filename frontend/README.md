# Interface do MIC-1.sim

O motor e o servidor sao escritos em C. A interface pronta fica em ../web.
Para apenas usar, abra ../iniciar.bat; Node.js nao e necessario.

Para editar a interface: Node.js 22.12+, npm ci, npm run build.
O build atualiza ../web. npm run dev usa o motor C na porta 3001.
Leia o README.md da raiz para a arquitetura e as regras do simulador.
